### 带宽标注方式要看清楚

香港VPS的带宽有两种标法：

1. **峰值带宽 + 月流量限制**：比如"200Mbps带宽/600GB月流量"，意思是瞬时能跑到200Mbps，但一个月用完600GB就断网或限速。适合访问量可预测的小站。
